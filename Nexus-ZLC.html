Uses the same frozen Nexus WebGPU backend for original and direct compressed matrix inference. The compressed path does not restore full weight matrices. Perplexity uses base-model logits with learned adapters, sampling and logit filters disabled.

This build accepts the pinned SmolLM2-135M F16/F16TRI1 and Q8_0/NHDMOD1 pairs, each with 128 held-out next-token targets. Both native software-adapter pilots are complete; your local run generates a separate report. This is a bounded pilot, not full-corpus perplexity.

Limits, privacy and reproducibility
Compression and restore work locally. WebGPU requires a supported browser and may require a secure context such as localhost. Run “python -m http.server 8000” in this folder if direct opening does not expose WebGPU, then visit localhost:8000.
Validation receipts distinguish byte-exact restoration, raw/direct logit agreement, perplexity, timing and explicit application-owned buffers. They do not measure total physical VRAM. Native software-adapter tests do not establish Radeon or browser performance. No production, speed or business-case claim is made.
Large files can require substantial host memory for conversion and verification. Cancel releases this operation’s worker; browser file/Blob caches may be managed separately. Enhanced pattern modes are not silently substituted for the frozen baseline.
